En **Mantenimiento → Usuarios** administra quién puede ingresar a FacilPOS. La lista muestra el código, el nombre y el estado (**ACTIVO**) de cada usuario.

## Registrar un usuario

Presione **+ Nuevo** y complete **Registrar usuario**:

| Campo | Descripción |
| --- | --- |
| Activo APP | Permite al usuario ingresar a FacilPOS. |
| Código | Código del usuario (por ejemplo, COS). |
| Nombre | Nombre de la persona. |
| Email | Correo del usuario. |
| Rol | **ADMINISTRADOR** o **VENTAS**. |
| Punto de venta | Punto de venta en el que el usuario registra sus ventas. De él depende la serie de sus comprobantes. |
| Nueva contraseña / Confirmar contraseña | Contraseña inicial del usuario. |

Presione **Registrar**. El usuario ya puede [ingresar](/primeros-pasos/ingreso) con el RUC de la empresa, su usuario y su contraseña.

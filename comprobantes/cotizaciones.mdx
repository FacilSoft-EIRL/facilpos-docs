Use **Comprobantes → Cotizaciones** para preparar una propuesta de precios para un cliente. Una cotización no emite un comprobante de venta.

El formulario funciona igual que el de [Registrar una venta](/comprobantes/registrar-venta): agrega ítems con **+ Añadir Item** y elige el cliente con **Seleccionar Cliente**.

## Campos del formulario

**Cabecera**: Numeración, Fecha de emisión, Moneda y Tipo de cambio.

**Datos adicionales**: Vendedor y Lista de precio.

**Datos de cotización**:

| Campo | Para qué sirve |
| --- | --- |
| Nombre de contacto | Persona del cliente que recibe la cotización. |
| Cargo de contacto | Cargo de esa persona. |
| Precios | Condiciones de precio de la oferta. |
| Validez de la Oferta | Tiempo durante el que se mantienen los precios. |
| Plazo de Entrega | Tiempo de entrega ofrecido. |
| Forma de Pago | Condiciones de pago ofrecidas. |
| Garantía | Garantía de los productos o servicios. |
| Comentario | Texto libre para el cliente. |
| Incluir IGV | Indica si los precios mostrados incluyen IGV. |

Cuando termine, presione **Registrar**.
